Protocol Documentation

LLM Verifier supports multiple protocols for AI coding assistant integration. This guide covers the three main protocols: ACP, MCP, and LSP.

Overview

Modern AI coding assistants communicate using standardized protocols. LLM Verifier tests and verifies that models correctly implement these protocols.

Why Protocol Verification Matters

Models that don't properly implement protocols may fail silently or provide incorrect responses in production environments. LLM Verifier ensures compatibility before deployment.

Protocol Purpose Use Case
ACP AI Coding Protocol Tool calling, code assistance
MCP Model Context Protocol Context management, multi-turn conversations
LSP Language Server Protocol Code intelligence, IDE integration

AI Coding Protocol (ACP)

ACP defines how AI coding assistants communicate with development environments using JSON-RPC.

Key Capabilities

  • JSON-RPC Protocol Comprehension - Understanding structured requests
  • Tool Calling - Invoking development tools correctly
  • Context Management - Maintaining session state
  • Code Assistance - Providing completions and refactoring
  • Error Detection - Identifying and reporting issues

Verification Command

# Verify ACP support for a model
acp-cli verify --model gpt-4 --provider openai

# Batch verify multiple models
acp-cli batch --models gpt-4,claude-3-opus,deepseek-chat

# Monitor ACP support over time
acp-cli monitor --models gpt-4 --interval 300

Scoring Criteria

ACP verification produces a score from 0.0 to 1.0:

  • 0.9-1.0: Excellent - Full ACP support
  • 0.8-0.9: Good - Minor issues
  • 0.7-0.8: Acceptable - Some limitations
  • Below 0.7: Failed - Insufficient support

Model Context Protocol (MCP)

MCP provides a standardized way to manage context across LLM interactions.

Key Capabilities

  • Context Window Management - Efficient use of token limits
  • Multi-turn Conversation - Maintaining conversation history
  • Token Awareness - Tracking context consumption
  • Context Compression - Summarizing long conversations

Configuration Example

mcp:
  enabled: true
  context_window_check: true
  max_context_tokens: 128000
  compression:
    enabled: true
    threshold: 0.8  # Compress when 80% full

Language Server Protocol (LSP)

LSP integration enables code intelligence features in development environments.

Key Capabilities

  • Code Completion - Intelligent suggestions
  • Diagnostics - Error and warning reporting
  • Go-to-Definition - Symbol navigation
  • Hover Information - Documentation on hover
  • Symbol Resolution - Finding references

Integration

lsp:
  enabled: true
  code_intelligence_check: true
  supported_languages:
    - go
    - python
    - javascript
    - typescript
