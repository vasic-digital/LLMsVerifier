Frequently Asked Questions

Is LLM Verifier free?

Yes, LLM Verifier is open source and free to use. Enterprise features are available for organizations requiring additional support.

Which AI providers are supported?

LLM Verifier supports 20+ providers including OpenAI, Anthropic, Google, Azure, Groq, Together AI, Fireworks, DeepSeek, Mistral, Cohere, and more.

Can I use LLM Verifier offline?

LLM Verifier requires internet connectivity to communicate with AI provider APIs. However, configuration export and some features work offline.

How do I update to the latest version?

Use go install github.com/llm-verifier/llm-verifier@latest or download the latest binary from our releases page.

Is my API key secure?

Yes. API keys are stored encrypted using SQLCipher, never logged, and only transmitted over HTTPS to provider APIs.

Can I contribute to LLM Verifier?

Absolutely! Check our Contributing Guide to get started.
