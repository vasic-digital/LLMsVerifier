Supported AI Providers

LLM Verifier supports 20+ AI model providers for comprehensive verification and benchmarking.

Major AI Providers

OpenAI

API Endpointhttps://api.openai.com/v1
Environment VariableOPENAI_API_KEY
Modelsgpt-4o, gpt-4-turbo, gpt-4, gpt-3.5-turbo, o1-preview, o1-mini
FeaturesChat, Embeddings, Images, Audio, Code, Function Calling
llm-verifier verify --provider openai --model gpt-4o
