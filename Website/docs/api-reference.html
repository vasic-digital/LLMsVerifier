API Reference

Complete REST API documentation for LLM Verifier. Base URL: http://localhost:8080/api/v1

Authentication

LLM Verifier uses JWT (JSON Web Tokens) for API authentication. Include the token in the Authorization header:

Authorization: Bearer <your-jwt-token>
POST /auth/login

Authenticate and receive a JWT token.

Request Body

{
  "username": "admin",
  "password": "your-password"
}

Response

{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expires_at": "2026-01-06T10:30:00Z",
    "user": {
      "id": "usr_123",
      "username": "admin",
      "role": "admin"
    }
  }
}
POST /auth/refresh

Refresh an existing JWT token.

Headers: Authorization: Bearer <token>

Response

{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expires_at": "2026-01-06T12:30:00Z"
  }
}
GET /auth/me

Get the current authenticated user.

Response

{
  "success": true,
  "data": {
    "id": "usr_123",
    "username": "admin",
    "email": "admin@example.com",
    "role": "admin",
    "created_at": "2026-01-01T00:00:00Z"
  }
}

Models

GET /models

List all verified models.

Query Parameters

provider string Filter by provider name
capability string Filter by capability (code-generation, streaming, etc.)
min_score number Minimum score threshold (0-10)
limit integer Number of results (default: 50, max: 100)
offset integer Offset for pagination

Response

{
  "success": true,
  "data": [
    {
      "id": "mdl_gpt4o",
      "name": "gpt-4o",
      "display_name": "gpt-4o (SC:8.5)",
      "provider": "openai",
      "score": 8.5,
      "verified": true,
      "verified_at": "2026-01-05T10:30:00Z",
      "capabilities": ["code-generation", "streaming", "multimodal"],
      "context_window": 128000,
      "max_output": 4096
    }
  ],
  "pagination": {
    "total": 45,
    "limit": 50,
    "offset": 0
  }
}

Verification

POST /models/{model_id}/verify

Start a verification job for a model. Returns immediately with a verification ID.

Path Parameters

model_id string The model ID or name to verify

Request Body (Optional)

{
  "timeout": "60s",
  "checks": ["availability", "code-understanding", "streaming"],
  "webhook_url": "https://your-server.com/webhook"
}

Response

{
  "success": true,
  "data": {
    "verification_id": "ver_abc123",
    "model_id": "mdl_gpt4o",
    "status": "running",
    "started_at": "2026-01-05T10:30:00Z"
  }
}
GET /verifications/{verification_id}

Get the status and results of a verification job.

Response (Running)

{
  "success": true,
  "data": {
    "verification_id": "ver_abc123",
    "model_id": "mdl_gpt4o",
    "status": "running",
    "progress": 60,
    "current_check": "code-understanding",
    "started_at": "2026-01-05T10:30:00Z"
  }
}

Response (Completed)

{
  "success": true,
  "data": {
    "verification_id": "ver_abc123",
    "model_id": "mdl_gpt4o",
    "status": "completed",
    "result": "verified",
    "score": 8.5,
    "checks": [
      {"name": "availability", "passed": true, "latency_ms": 150},
      {"name": "authentication", "passed": true},
      {"name": "code-understanding", "passed": true, "accuracy": 0.95},
      {"name": "streaming", "passed": true}
    ],
    "started_at": "2026-01-05T10:30:00Z",
    "completed_at": "2026-01-05T10:30:45Z"

}

Configuration

GET /config/export/{format}

Export verified configuration in specified format.

Path Parameters

format string Export format: opencode, crush, claude-code, json

Query Parameters

providers string Comma-separated provider names
include_api_keys boolean Include API keys in export (default: false)

Response (OpenCode format)

{
  "llms": {
    "openai": {
      "endpoint": "https://api.openai.com/v1",
      "models": ["gpt-4o (SC:8.5)", "gpt-4 (SC:8.2)", "gpt-3.5-turbo (SC:7.5)"]
    },
    "anthropic": {
      "endpoint": "https://api.anthropic.com",
      "models": ["claude-3-opus (SC:9.0)", "claude-3-sonnet (SC:8.5)"]
    }
  }
}

Error Codes

Code Status Description
AUTH_REQUIRED 401 Authentication token is missing
AUTH_INVALID 401 Authentication token is invalid or expired
FORBIDDEN 403 User does not have permission for this action
NOT_FOUND 404 Requested resource does not exist
RATE_LIMITED 429 Too many requests, retry after rate limit resets
VALIDATION_ERROR 400 Request validation failed
PROVIDER_ERROR 502 Upstream provider returned an error
INTERNAL_ERROR 500 Internal server error

Error Response Format

{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid model ID format",
    "details": {
      "field": "model_id",
      "reason": "must be alphanumeric with underscores"
    }
  }
}

Pagination

List endpoints support pagination with limit and offset parameters:

GET /api/v1/models?limit=20&offset=40

Responses include pagination metadata:

{
  "data": [...],
  "pagination": {
    "total": 95,
    "limit": 20,
    "offset": 40,
    "has_more": true
  }
}

Rate Limiting

API requests are rate-limited based on your plan:

Plan Requests/Minute Verifications/Hour
Free 60 10
Pro 300 100
Enterprise Unlimited Unlimited

Rate limit headers are included in all responses:

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 45
X-RateLimit-Reset: 1704456000
