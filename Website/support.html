Frequently Asked Questions

How do I resolve ProviderInitError in OpenCode?

Use LLM Verifier to generate a correctly formatted configuration:

llm-verifier verify --provider openai --model gpt-4o
llm-verifier export-config opencode --output config.json

Then copy the generated config.json to your OpenCode configuration directory.

Which providers are supported?

LLM Verifier supports 20+ providers including OpenAI, Anthropic, Google (Gemini), Groq, DeepSeek, Mistral, Together AI, Fireworks AI, Perplexity, Azure OpenAI, AWS Bedrock, Cohere, xAI, Cerebras, Replicate, Cloudflare AI, SiliconFlow, Ollama, and OpenRouter.

View full provider list

How do I add a custom provider?

Custom providers can be added by implementing the provider interface in Go:

llm-verifier providers add \
  --name my-provider \
  --endpoint https://api.myprovider.com/v1 \
  --api-key $MY_PROVIDER_API_KEY

See the Developer Guide for detailed instructions.

How do I run verification in CI/CD?

LLM Verifier integrates easily with CI/CD pipelines:

- name: Verify AI Models
  run: |
    llm-verifier verify --provider openai --model gpt-4o --json > results.json
    llm-verifier export-config opencode --output config.json
  env:
    OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}

What does the (SC:X.X) suffix mean?

The (SC:X.X) suffix indicates the LLMsVerifier-calculated score for a model. This score (0-10) reflects overall model quality based on speed, efficiency, cost, capability, and recency metrics. Higher scores indicate better-performing models.

Common Issues

API Key Invalid

Symptom: "Invalid API key" or "Authentication failed" errors

Solution:

  • Verify the API key is correctly set: echo $OPENAI_API_KEY
  • Check if the key has expired or been revoked
  • Ensure no extra whitespace in the key

Rate Limiting

Symptom: "Rate limit exceeded" or 429 status codes

Solution:

  • Reduce parallel verification: --parallel 1
  • Add delay between requests: --request-delay 5s
  • Upgrade your API plan for higher limits

Timeout Errors

Symptom: "Request timeout" or connection errors

Solution:

  • Increase timeout: --timeout 60s
  • Check your network connection
  • Verify the provider API is accessible

Configuration Export Fails

Symptom: Invalid JSON or schema errors in exported config

Solution:

  • Validate config: llm-verifier config validate
  • Check OpenCode version compatibility
  • Use --format opencode-v2 for newer versions
